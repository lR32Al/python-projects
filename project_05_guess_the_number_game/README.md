# 🎯 Guess the Number Game

A simple Python console game where the player has to guess a randomly generated number between 1 and 10.  
This project demonstrates the use of loops, conditionals, and user input handling in Python — perfect for beginners.

---

## 🚀 How It Works

1. The program randomly generates a number between **1 and 10**.
2. The player has **3 attempts** to guess the correct number.
3. After each incorrect guess, the game shows how many attempts remain.
4. If the player guesses correctly, the game prints **"You win! 🎉"**.
5. If all attempts are used, it reveals the correct number and ends with **"Game over! 😢"**.

---

## ✨ Features

- 🎲 Random number generation using the `random` module
- ⏳ Limited attempts (3 tries per game)
- 💬 Interactive feedback for each guess
