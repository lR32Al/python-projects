# 🧮 Multiplication Table Generator

A simple Python program that generates the multiplication table for any number entered by the user.

---

## 🚀 How It Works

1. The program asks the user to **enter a number**.
2. Using a **for loop**, it multiplies that number by integers from 1 to 10.
3. It prints the complete multiplication table in a clean and formatted style.

---

## ✨ Features

- 🔢 Accepts any number from the user
- 🔁 Uses a simple **for loop** to generate results
- 📄 Displays a clean multiplication table format
